Purchase Domain, Free Hosting on github Pages

Purchase a domain

Suppose you have purchased ydadigitals.com

Create a website using github pages

ydadigitals.github.io

GitHub Settings

Go to repository of create website(ydadigitals.github.io) > Settings > Pages. Under Custom domain, enter Purchased domain on hostinger(ydadigitals.com) and save.

Update Hostinger DNS Records

ALIAS record
  Hostinger DNS nameservers > Manage DNS Records > Type=CNAME, Name=@, Point to=ydadigitals.github.io, TTL=14400

CNAME record
  Type=CNAME,name=www, point to=ydadigitals.com TTL=300

MX records
  All MX records (for email delivery). Since using zoho mail for mail delivery

TXT Records
  TXT @ "v=spf1 include:zohomail.com ~all" (SPF for email authentication)
  TXT @ "zoho-verification=..." (Zoho verification)
  TXT zmail._domainkey (DKIM for email)

CAA Records
  All CAA records (certificate authorities, safe to keep)

And also donot delete any record related to github or zoho
